# BPE from Scratch

Implementing **Byte Pair Encoding (BPE)** tokenization from scratch in Python, inspired by Andrej Karpathy's [minbpe](https://github.com/karpathy/minbpe).

## About

This is a learning project focused on understanding how tokenization works in modern Large Language Models (LLMs).

The goal is to implement BPE step by step, without relying on existing tokenizer libraries or copying reference implementations.
